# Seed: Baseline Reset onto Upstream v2.5.0

Strategy chosen 2026-08-24 during `/gsd-explore`: **stay forked, reset the
baseline.** Evidence and measurements in
[`../notes/upstream-v2-divergence-analysis.md`](../notes/upstream-v2-divergence-analysis.md).

Rejected: rebasing 184 code commits across 45 mutually-touched files; a
cherry-pick campaign with the same conflict surface serialized; freezing at
1.3.3-beta; upstreaming the features and retiring the fork.

## Shape

**Phase A — Divergence contract (before the reset).** Generalize the existing
negative-assertion tripwire (`tests/cli/init.test.ts:462`) into a complete
contract over the template set and hook registration. Derive the coupled-artifact
list by diffing the fork's `src/templates/` against upstream's — no merge
required. Must pass on 1.3.3-beta before anything else moves.

**Phase B — Baseline reset.** Establish a branch from `upstream/main` at v2.5.0.
Take upstream wholesale for everything not on the re-port list. The 142
planning-only commits do not travel.

**Phase C — Re-port the five fork-unique pillars.**

1. R7a/R7b + R9 — curation machinery (propose-mode, `openwolf learnings
   check/accept`, `wolf-pantry` aggregator, freshness sidecar). Highest value,
   zero upstream equivalent, and the reason the fork exists.
2. R4 — authored-vs-derived `.wolf/.gitignore` template, including the
   `daemon-token.tmp` / `daemon.log` / `dashboard.log` rules added in `9ebf045`.
3. R11 — framework-blind resume protocol + `execution_layer` config slot;
   re-delete `STATUS.md`.
4. Registry canonicalization (`realpathSync` symlink dedup).
5. `buglog.ndjson` format + `migrate-buglog`.

Plus the fork tooling: `install-dev.sh`, `install-global.sh`,
`sync-upstream.sh` (branch detection fixed in `4876182`).

**Phase D — Retire the duplicates.** Delete `wolf-lock.ts`, `wolf-json.ts`,
`wolf-ignore.ts` in favour of upstream's `withFileLock` and `exclude_patterns`
— *conditional* on the research question confirming they cover the acme field
cases. If they don't, the fork versions survive and this phase inverts.

**Phase E — Adopt selectively.** `memory-migrate.ts` (cerebrum → Claude Code
native memory) is the lead candidate; D-14 permits it, correctly scoped. Also
evaluate `src/agents/*` multi-host snippets, `map`/`find`/`report`, and the
expanded hook set.

## Constraints carried in

- **Consumer migration is a hard gate.** acme_translators and
  iconik-spectra-riobroker run `buglog.ndjson` on 1.3.3-beta; a v2.5.0 base
  ships `buglog.json`. No consumer takes the reset before a migration path
  exists. See the pending todo.
- **Establish a sync cadence.** The whole point of resetting rather than
  freezing is that the next gap should be weeks, not 4.5 months. A working
  `sync-upstream.sh` now exists to measure it honestly.
- **Version/milestone decoupling holds.** Milestone IDs and software versions
  diverge in this repo by design; label them separately.
- **Deferred items may be moot.** R10 (cerebrum provenance) and R12
  (pantry-owner role) were deferred to a rollout milestone. Both touch cerebrum
  machinery that upstream has been rewriting — re-scope them against v2.5.0
  before scheduling.
