<objective>
Fix the HOOK_FILES deployment gap by replacing the static file-copy list with dynamic directory scanning. The static `HOOK_FILES` array in `hook-settings.ts:156` lists only 8 files but misses all 6 `wolf-*.js` modules created in the hook module split. At runtime, `shared.js` imports from `./wolf-paths.js` which is never copied to `.wolf/hooks/`, causing `ERR_MODULE_NOT_FOUND`.

Purpose: Eliminate drift between the compile output and deployed hooks (per D-02). Any new `wolf-*` module added in the future is automatically deployed without updating a separate list.
Output: Shared hook-copy module, updated init/update/status CLIs, removed static HOOK_FILES.
</objective>

  Export these four functions:

  1. **`findHookSourceDir(): string | null`** — Identical candidate search logic to the existing duplicated implementations in `init.ts:73-83` and `update.ts:325-337`. Looks for compiled hooks relative to `__dirname` (dist/cli/) at:
     - `path.resolve(__dirname, "../hooks")`

     - Verify the directory exists AND contains `shared.js` (`fs.existsSync(path.join(candidate, "shared.js"))`)
     - Return the first match, or `null` if none found.

  2. **`getHookFileNames(sourceDir: string): string[]`** — Dynamic discovery. Call `fs.readdirSync(sourceDir)`, filter to `.js` files only (`f.endsWith(".js")`), return the sorted array. This replaces the static `HOOK_FILES` iteration.

  3. **`copyHookFiles(sourceDir: string, destDir: string): number`** — Iterates `getHookFileNames(sourceDir)`, calls `safeCopyFile(path.join(sourceDir, file), path.join(destDir, file))` for each. Returns the count of successfully copied files (use `fs.existsSync(srcPath)` guard per file like the existing code). Import `safeCopyFile` from `../utils/fs-safe.js`. Use `ensureDir` from `../utils/paths.js` to ensure `destDir` exists before copying.

  4. **`writeHooksPackageJson(hooksDir: string): void`** — Writes `{"type": "module"}` to `path.join(hooksDir, "package.json")`. Exact same content as existing: `JSON.stringify({ type: "module" }, null, 2) + "\n"`.

  Import conventions per CONVENTIONS.md: `node:` prefix for built-ins, `.js` extension in relative imports, named exports only.

  Do NOT import from `hook-settings.ts` — this module replaces the `HOOK_FILES` dependency.
  </action>
