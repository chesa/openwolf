<objective>
Add a `.wolf/.gitignore` template for the mixed commit strategy, replacing the current approach of appending `.wolf/` to the project-root `.gitignore`. The `.wolf/.gitignore` uses a `*` ignore-all pattern with opt-in exceptions for files that should be committed (`.gitignore`, `OPENWOLF.md`, `config.json`, `identity.md`).

Purpose: Enable selective tracking of `.wolf/` files. Users opt files into version control by removing lines from `.wolf/.gitignore`, rather than the all-or-nothing `.wolf/` ignore in the project `.gitignore`. This supports the "commit config, ignore state" mixed strategy.
Output: Template file at `src/templates/.gitignore`, updated `init.ts` to write it on initalization and remove the old project-root `.gitignore` append.
</objective>
